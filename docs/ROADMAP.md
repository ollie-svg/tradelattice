# Roadmap

## v0.1 (current)
Schema (6 record types), three Canadian connectors (CBSA tariff, CanadaBuys, StatCan trade), FastAPI service with SQLite, static web UI, landed-cost estimate (duty only).

## Deferred (non-goals for v0.1)
- Authentication and authorization
- Multi-tenant deployments
- GST/PST and other taxes in landed cost
- Currency conversion
- Real-time feeds
- ML (matching, forecasting, classification)

## Later ideas
- Additional connectors (provincial tenders, port data, supplier registries)
- Postgres-first deployment guide
- Schema v0.2 based on adopter feedback
- Other countries' tariff and procurement connectors
