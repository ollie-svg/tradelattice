# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Report privately using GitHub's "Report a vulnerability" (Security Advisories) feature on this repository. Include steps to reproduce and the affected version or commit.

We aim to acknowledge reports within 5 business days and to provide a fix or mitigation plan within 30 days.

## Scope

v0.1 has no authentication and is intended for local or trusted-network use; do not expose it to the public internet. Auth is listed in `docs/ROADMAP.md`.

## Supported versions

Only the latest release receives security fixes.
